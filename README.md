# OR-ToolKit 🧰

**The شنطة العدة (Toolbox) of Operations Research**

A comprehensive, browser-based web application for solving Operations Research problems with step-by-step solutions. Built entirely with HTML, CSS, and vanilla JavaScript — no backend required.

---

## 🌟 Overview

OR-ToolKit is an educational and practical tool designed for students, professors, and professionals in Operations Research, Management Science, and Industrial Engineering. It provides interactive solvers and code generators that run completely in the browser, offering detailed step-by-step calculations for learning and verification.
